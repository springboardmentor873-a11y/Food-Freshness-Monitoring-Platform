## 🔬 Core Features & Modules

### 1. Multi-Spectral AI Vision Food Scanner
- Upload photos or capture directly with device camera.
- Analyzes surface discoloration, skin texture firmness, chlorophyll index, and fungal spore formation.
- Computes an exact **Freshness Score (0–100)**, classification, remaining shelf life, and spoilage risk percentage.

### 2. Five Persona-Specific Workspaces (RBAC)
- 🛒 **Consumer (Smart Kitchen)**: Pantry inventory, expiration reminders, scan-to-cook priorities, and recipe suggestions.
- 🏪 **Retail Manager (Supermarket)**: FIFO batch rotation, automated markdown pricing suggestions, and shelf monitoring.
- 🏭 **Warehouse Operator (Cold Logistics)**: Pallet tracking, cold-room climate control, and logistics dispatch readiness.
- 🔬 **Food Quality Inspector (Lab & Safety)**: Standardized HACCP / ISO compliance scoring and exportable audit certificates.
- ⚡ **Administrator**: Tenant user management, model telemetry, and system-wide waste reduction metrics.

### 3. IoT Cold-Chain & Atmosphere Telemetry
- Real-time environmental tracking for Temperature (°C), Relative Humidity (%), Ethylene gas ($C_2H_4$ ppm), and $CO_2$ levels.
- Automated sensor anomaly detection with instant alerts.

### 4. Prescriptive Recommendations Engine
- Actionable heuristics for food storage optimization, inventory markdown execution, and humidity regulation.

## 🚀 Quickstart & Setup Guide

### Prerequisites
- **Node.js**: `v18.0.0` or higher (v20+ recommended)
- **npm** (v9+) or `bun` / `pnpm` / `yarn`
- **Google Gemini API Key**: [Get a Gemini API Key](https://aistudio.google.com/)

---

### Step-by-Step Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/freshsense-ai.git
   cd freshsense-ai
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   ```bash
   cp .env.example .env
   ```
   Open `.env` and configure:
   ```env
   # Google Gemini API Key for multi-modal vision analysis
   GEMINI_API_KEY=your_gemini_api_key_here

   # Port configuration (default: 3000)
   PORT=3000
   ```
   > 💡 *Note: If `GEMINI_API_KEY` is not provided, FreshSense AI automatically operates in interactive demo mode using its built-in deterministic heuristic engine.*

4. **Start Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔌 Backend API Reference

### 1. Health Check
```http
GET /api/health
```
**Response:**
```json
{
  "status": "ok",
  "service": "FreshSense AI Vision Engine",
  "hasApiKey": true,
  "timestamp": "2026-08-22T10:00:00.000Z"
}
```

### 2. Multi-Modal Vision Analysis
```http
POST /api/v1/analyze-food
Content-Type: application/json
```
**Request Body:**
```json
{
  "imageBase64": "data:image/jpeg;base64,...",
  "foodName": "Organic Strawberries",
  "category": "Fruits",
  "temperature": 4,
  "humidity": 85,
  "storageDays": 2
}
```
**Response:**
```json
{

    "visualConditionScore": 38,
    "storageConditionScore": 24,
    "shelfLifeScore": 18,
    "chronologicalAgeScore": 14
  },
  "recommendations": [
    "Maintain cold chain at 2-4°C",
```
